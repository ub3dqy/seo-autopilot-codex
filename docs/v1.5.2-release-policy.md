# v1.5.2 release policy

The source PR may be merged only after the exact GitHub branch archive passes the complete local release gate. The final binary release must be rebuilt from the merged source tree, verified twice for determinism, executed directly from both ZIP editions, published with SHA-256/SBOM/evidence, downloaded again, and compared byte-for-byte.

The one-link bootstrap must remain pinned to v1.5.1 until the v1.5.2 release assets and their exact hashes exist. A second verified documentation commit then updates `README.md`, `START_AUTOPILOT.md`, and `START_AUTOPILOT_EN.md` to v1.5.2.

```text
GitHub Actions: BLOCKED_EXTERNAL / WAIVED_BY_OWNER
Release gate: LOCAL VERIFICATION ONLY
```
