# v1.5.2 acceptance criteria

The release is acceptable only when all of the following hold:

```text
findings from artifacts/** = 0
findings from tmp/** = 0
A-level fixes outside CURRENT_SOURCE = 0
browser profile content reads = 0
browser profiles reported as EXCLUDED_SENSITIVE = true
source-scope manifest present in run.json = true
Next.js framework findings structured in run.json = true
REVIEW_REQUIRED presented as review, not failure = true
repeat audit deterministic = true
full local release gate = PASS
```

The AIRSYS-shaped regression and the complete local release gate enforce these conditions.
