# v1.5.2 verification summary

This document defines the required evidence and does not substitute a real local run.

The earlier statement that the final candidate had already passed every local platform gate was withdrawn after the Windows run on 2026-08-26 exposed a harness encoding failure: `verify_local.py` attempted to print Unicode replacement text to a CP1251 stream and aborted before it could record the unit-test result.

The branch now contains a UTF-8-safe Windows entry point and a CP1251-strict regression. The exact updated candidate must complete:

```text
VERIFY_LOCAL_WINDOWS.cmd --release
```

or, on a UTF-8-safe portable environment:

```bash
python scripts/verify_local.py --release
```

Release evidence is valid only when `status=PASS`, `mode=release`, every recorded step is `PASS`, the Git tree is clean, and the evidence identifies the exact candidate or merged commit.

```text
GitHub Actions: BLOCKED_EXTERNAL / WAIVED_BY_OWNER
Release gate: LOCAL VERIFICATION ONLY
```
