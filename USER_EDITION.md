# User Edition

Run `python prepare_editions.py` (or the platform launcher in the repository root) to materialize the complete User Edition into `user/`.

The exact release ZIP is built with `python prepare_editions.py --build-zips` and verified against SHA-256 `e03e522fb7767ad7597452fac78cb982aac4c83337573054a32b3f19516d399e`.
